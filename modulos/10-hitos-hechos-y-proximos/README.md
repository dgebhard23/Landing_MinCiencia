# Hitos: completados y próximos

**Categoría:** Calendario y proceso
**Viene de:** Landing Reglamentos TT (versión larga)

## Qué hace
Una sola lista de hitos con fecha se reparte sola en dos columnas: «Completado» (del más reciente al más antiguo) y «Lo que viene» (los próximos seis, con el resto resumido). Marca el próximo hito y cuántos días faltan.

## Cuándo usarlo
Bitácoras de avance, transparencia de procesos, páginas de seguimiento de un programa.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
