# Pestañas accesibles

**Categoría:** Interacción
**Viene de:** Home EBCT y «3er registro EBCT» (pestañas Ecosistema / Trayectoria / Startup Ciencia)

## Qué hace
Pestañas con roles ARIA, navegación con flechas del teclado, y aviso al contenido cuando se muestra (útil para dibujar gráficos solo cuando se ven). Recuerda la pestaña elegida en la URL (#pestana).

## Cuándo usarlo
Separar perfiles, años, regiones o instrumentos en una misma sección sin alargar la página.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
