# Gráficos que toman los colores de la marca

**Categoría:** Datos
**Viene de:** Home EBCT y «3er registro EBCT»

## Qué hace
Barras, dona y líneas con Chart.js, configurados para leer la paleta desde los tokens (--serie-1 … --serie-6), con formato chileno de números y dibujados solo cuando su pestaña o sección se ve.

## Cuándo usarlo
Resultados de encuestas, registros (como el 3er registro EBCT), indicadores de un programa.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
