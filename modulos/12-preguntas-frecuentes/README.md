# Preguntas frecuentes con buscador y filtros

**Categoría:** Interacción
**Viene de:** Landing Reglamentos TT (FAQ) + FAQ web EBCT (filtros y buscador)

## Qué hace
Acordeón accesible (una pregunta abierta a la vez) con un buscador que filtra mientras escribes, resalta las coincidencias y filtra por tema con contadores. Con «no encontramos resultados» y enlace a contacto.

## Cuándo usarlo
FAQ de convocatorias, trámites, programas. Combina bien con el módulo 17 para que el contenido salga de una planilla.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
