# Títulos que suben línea a línea

**Categoría:** Movimiento
**Viene de:** Landing Reglamentos TT (antes con GSAP; aquí sin dependencias)

## Qué hace
Cada línea de un título sube detrás de una máscara cuando el título entra en pantalla. Sin librerías: usa IntersectionObserver y transiciones CSS.

## Cuándo usarlo
Títulos de sección grandes, para dar ritmo editorial al recorrer la página.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
