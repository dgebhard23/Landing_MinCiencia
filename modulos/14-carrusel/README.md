# Carrusel liviano (sin jQuery)

**Categoría:** Interacción
**Viene de:** Home EBCT (carruseles Asuntos regulatorios y Catálisis, antes con Bootstrap/jQuery)

## Qué hace
Carrusel con scroll-snap nativo: se desliza con el dedo, flechas, puntos, teclado y avance automático que se pausa al pasar el mouse o al enfocar. Acepta imágenes de Google Drive pegando su enlace.

## Cuándo usarlo
Fotos de actividades, logos de beneficiarios, testimonios, noticias.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
