# Copiar, compartir y avisos breves

**Categoría:** Utilidades
**Viene de:** Buzón EBCT (copiar folio) y home EBCT

## Qué hace
Botones para copiar un texto o enlace (con respaldo si el navegador no lo permite), compartir con el menú nativo del celular (o WhatsApp, LinkedIn y correo en escritorio) y un aviso flotante breve («Copiado ✓») reutilizable.

## Cuándo usarlo
Compartir una convocatoria, copiar un folio de seguimiento del buzón, difundir en redes.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
