# Zona de adjuntos (arrastrar y soltar)

**Categoría:** Formularios
**Viene de:** Buzón EBCT

## Qué hace
Caja para subir archivos con clic, teclado o arrastrando. Valida tipo, tamaño por archivo y tope total; muestra la lista con peso y botón para quitar; entrega los archivos en base64 listos para mandar a Apps Script.

## Cuándo usarlo
Respaldos de postulaciones, documentos de antecedentes, evidencia en un buzón.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
