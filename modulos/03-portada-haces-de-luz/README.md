# Portada con haces de luz animados

**Categoría:** Portada
**Viene de:** Landing Reglamentos TT (portada)

## Qué hace
Fondo de portada dibujado en canvas: curvas finas de luz que ondulan lentamente, en mezcla aditiva. Toma los colores de los tokens, se pausa fuera de pantalla y queda quieto si el usuario pidió reducir el movimiento.

## Cuándo usarlo
Portadas institucionales que necesitan presencia sin usar fotos o video. Pesa casi nada.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
