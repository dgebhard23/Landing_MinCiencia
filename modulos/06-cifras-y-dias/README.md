# Cifras clave con conteo y días al plazo

**Categoría:** Contenido
**Viene de:** Landing Reglamentos TT (datos clave) y home EBCT (KPI)

## Qué hace
Bloque de cifras grandes que cuentan desde cero al aparecer. Una cifra puede ser automática: los días que faltan para una fecha (plazo legal, cierre, evento).

## Cuándo usarlo
Datos clave de un programa, resultados, o el «quedan N días» de una convocatoria.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
