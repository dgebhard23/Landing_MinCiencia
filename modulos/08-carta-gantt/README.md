# Carta Gantt con estados y marca de hoy

**Categoría:** Calendario y proceso
**Viene de:** Landing Reglamentos TT («La ruta»)

## Qué hace
Línea de tiempo por meses: cada barra se ubica y dimensiona sola a partir de sus fechas, se colorea por tipo de actor y por estado (hecho, en curso, próximo). Incluye la línea de «hoy», banderas de hitos y el texto «Fase en curso».

## Cuándo usarlo
Planes de trabajo, procesos regulatorios, programas con etapas, cronogramas de licitaciones.

## Cómo agregarlo a una landing
1. Copia `modulo.css` y `modulo.js` a tu proyecto (o enlázalos).
2. Copia el marcado HTML desde `index.html` (todo lo que está entre el `<header class="demo-cab">` y el `<script>`).
3. Asegúrate de cargar antes `base/tokens.css` y `base/base.css`: los colores salen de ahí.

Abre `index.html` en el navegador para verlo funcionando.
